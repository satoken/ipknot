# オリジナルDirks–PierceエネルギーからIPknotのスコアへの変換

物理パラメータを固定したオリジナルDPのPK固有項を使い、線形補正、局所Boltzmannモデル、
既存DD候補内のGibbs分布を比較する。まず線形補正を対照として局所的な確率変換を
projected/crossingで試す設計が扱いやすい。候補集合の変換は構造の整合性を保つ比較対象になる。
以下は設計と[数値プロトタイプ](dp_score_conversion.py)の検討記録。
その後のnative実装・RNA精度評価・DD速度測定は
[dp_conversion_evaluation.md](dp_conversion_evaluation.md)にまとめた。

## 元のエネルギーと尺度

[Dirks–Pierce (2003), Eq.16とResults](https://www.its.caltech.edu/~niles/chebe163/papers/dirks03.pdf)の外側PKループ項：

```text
G_PK = beta1 + beta2*B_p + beta3*U_p  [kcal/mol]
beta1=9.6, beta2=0.1, beta3=0.1
multiloop内・別PK内の開始項は15.0
```

B_pはPK内部の境界対数で、ステムの全対数ではない。
追加構造のない二本ステムのH型ではB_p=2、U_p=L1+L2+L3、すなわち `G_PK=9.8+0.1*U_p`。
原著の探索前の値やHotKnotsの変種と混ぜない。この限定したH型の式は[現在の実装](../../src/pk_energy.cpp)と一致する。
入れ子の文脈はIPknotのレベル番号と同じではない。現在のspan採点はループ内に別の対合がある場合にU_pを近似する。
複数のブロック対の和は、開始項を一PKにつき一度数える構造全体のDPエネルギーとは一致しない。
塩基配列を特徴に使わない条件を維持するため、配列依存の通常のnearest-neighbor項は追加しない。

IPknotの係数は `alpha_l*(p_ij-t_l)`。確率から作る期待利得である。
37℃のRTは0.6163314 kcal/mol。`q=G_PK/(RT)` とすれば無次元になるが、
これだけで期待利得との尺度や加算する対象が揃うわけではない。
また `exp(-q)` は正規化前の重みであり、成立確率ではない。

| 未対合塩基数U_p | G_PK (kcal/mol) | exp(-G_PK/RT) |
|---|---:|---:|
| 0 | 9.8 | 1.24e−7 |
| 10 | 10.8 | 2.45e−8 |
| 20 | 11.8 | 4.84e−9 |
| 40 | 13.8 | 1.89e−10 |

完全なエネルギーモデルではステムの安定化等も寄与する。正のループ項だけをPKなしの重み1と比較すると、PKを極端に抑える。
確率への変換には、比較状態、その重み・縮退度、基準分布を定義する必要がある。

## 1. 線形の目的関数補正

```text
Phi_m = b - lambda_E*q_m
w_AB = Phi_m/(A*B)
```

物理パラメータは固定し、bとlambda_EだけをIPknotの目的関数の尺度で調整する。
現在の `--pk-energy-intercept` / `--pk-energy-scale` はこの方式。
`b=lambda_E*q_ref` とすれば `Phi=lambda_E*(q_ref-q)` と書ける。
ただし基準コストを引くことはPK状態への事前の加点であり、単なる単位変換ではない。
H型でbを自由にすると原著の定数開始項を相殺できるため、b=0も対照に含める。

同じPhiを全ブロック対に与えるか、一対あたりの補正として `Phi=(A+B)*d_m` とするかは別の選択。
後者は期待塩基対数の尺度に近く、ブロック対あたり固定の上限で長いPKへの補正が弱くなることを避けられる。
前回の評価ではAB正規化だけでも精度が変わったため、変換式と長さ配分を同時に変えた効果を混同しない。
候補ブロック対ごとにO(1)。整数変数を増やさないが、物理的な事後確率を与えるものではない。

## 2. 局所Boltzmann分布と期待塩基対数

二本のステムの存在を表す局所変数Y_A,Y_Bについて、00、10、01、11の4状態を定義する。
仮の成立確率をa,bとし、基準の重みを独立な事前として置く。

```text
Q00=(1-a)*(1-b), Q10=a*(1-b), Q01=(1-a)*b, Q11=a*b
J=eta-tau*G_PK/(RT)
Z=Q00+Q10+Q01+Q11*exp(J)
P11=Q11*exp(J)/Z
P10=Q10/Z, P01=Q01/Z, P00=Q00/Z
```

tau=1、eta=0がループ項をそのままBoltzmann因子にする条件。
tau<1は統計的なtemperingであり、LPCや実際の実験温度を変更しない。
etaはPK状態に与える基準のlog-weight。基準コストG_refを使うと `eta=tau*G_ref/(RT)`。
`P11=sigmoid(logit(a*b)+J)` とも書け、対数オッズへエネルギー差を加える変換となる。
調整しても元のDPパラメータは固定するが、自由なetaは開始項を相殺し得るため、物理分布と較正済み近似を区別する。

各ステムが一括して成立する局所モデルでは

```text
r_A=P10+P11, r_B=P01+P11
Phi_m=kappa*[A*(r_A-a)+B*(r_B-b)]
```

が基準に対する期待塩基対数の変化となる。既存支持を丸ごと再加算せず、変化分を使う。
レベル重みを考慮する場合はA項とB項に対応するalpha_lを掛ける。
kappaを0〜1とすれば、局所的には基準期待値と補正後期待値の混合と解釈できる。
比較状態を含む完全な自由エネルギー差がないため、仮定した基準分布を持つ局所近似である。

- BPPは各対の周辺確率で、ステム全体の成立確率a,bを一意には与えない。
  平均・最小BPPや各対オッズの集約はproxyとして扱う。単純積の長さ依存や、相関を無視した過度なオッズ加算に注意する。
- PKフリー分布では交差対の同時成立確率は0。Q11=a*bはそこから導いた値ではなく、
  PKを許す新しい局所事前の仮定。PKフリー分布へ因子を掛けるだけでは確率0のPK状態を作れない。

重なるモチーフのPを足しても、全体の塩基容量や競合の整合性は保証できない。
この方式ではPをグローバルなBPPとして置き換えず、接点係数の補正に利用する。
部分ステムのcrossing配分、採点相手の成立を要求しないprojected配分はさらに近似を加える。
その配分で全体の厳密なMEAを最適化しているとは言えない。

基準J=0の周りでは

```text
dPhi/dG = -kappa*tau/(RT) * a*b * [A*(1-a)+B*(1-b)]
```

となり、支持と不確実性に応じて弱める線形エネルギー罰則とも読める。
PKフリーBPPで真の第二ステムが弱いと補正も小さくなるため、形状だけの較正済みsigmoidも比較対象になる。
ステム要約の再利用後は候補ブロック対ごとにO(1)。安定したsigmoid/log-sum-expを使う。
変数・因子の数と固定beam等の計算量を維持できるが、定数費用や反復数の変化は実測が必要。

## 3. 既存DD候補集合に限定したGibbs分布

自動閾値探索・DD回復がすでに生成する、実行可能な構造S_kの有限集合Cを再利用する。

```text
log W_k = F_BPP(S_k)/T_score - lambda_E*G_PK(S_k)/(RT)
P_k = W_k / sum_h W_h
p_tilde(i,j) = sum_k P_k * I[(i,j) in S_k]
```

F_BPPには全候補に共通の固定した閾値・重みを使う。
異なる自動閾値solveの目的値をそのまま候補間で比較しない。
T_scoreは期待利得をlog-weightへ変換する統計的な尺度。
G_PKは選択された構造に定義したDP固有項で、複雑なPKの分解・ループ内対合・開始文脈を正確に数える実装は別途必要。
現在の部分ブロックスコアを原著の完全な構造自由エネルギーと呼ばない。

Pは限定集合とハイブリッドスコアに対して正規化された確率。
p_tildeは実行可能構造の混合なので、各塩基の `sum_j p_tilde(i,j)<=1` を満たし、共有塩基や競合を扱える。
全RNA構造に対するDP熱力学のBPPではなく、候補集合に条件付けた確率である。
同じ物理構造の別反復・別閾値・別レベル分解は一度だけ数える。
レベル分解ごとの基準目的値には最良分解等の固定規則を置く。探索訪問数を熱力学的な縮退として数えない。

追加求解をしない比較ではCの中からp_tildeによる期待利得が最大の構造を選ぶ。
これはCに限定したMEAであり、Pの最大値の構造を選ぶMAPとは異なる。
新係数でDDを解き直すなら追加DD求解が必要なので別条件にする。
候補外の構造や塩基対を回復できず、候補が一つなら予測は変わらない。
正規化はO(K)、周辺確率集計は候補内塩基対の総数に線形。候補保存・重複除去・エネルギー評価には追加費用がある。
完全なPK分配関数を計算するオリジナルDPのO(n^5)手法は、今回の高速化条件から外す。

## 数値監査と実験の設計

[dp_score_conversion.py](dp_score_conversion.py)は人工値だけを使い、[監査結果](measurements/dp-score-conversion-audit.json)を作る。
10,000ケースで局所式と独立な4状態列挙を比較し、最大絶対誤差8.88e−16。
正規化、期待値、ゼロ補正、極端な指数、確率0の支持を新たに作れない性質を確認した。
候補集合モデルでは容量制約、期待塩基対数、重複訪問・共通エネルギー移動の不変性を検算した。
RNAや塩基配列を読まず、学習もしていないため、これらは精度の証拠ではない。

人工的な事前a=b=0.9、A=B=5、基準U_ref=20、tau=0.1の場合：

| U_p | 較正例のP11 | 期待塩基対数の変化Phi（kappa=1） |
|---|---:|---:|
| 0 | 0.85502 | +0.23694 |
| 10 | 0.83372 | +0.12487 |
| 20 | 0.81000 | 0 |
| 40 | 0.75501 | −0.28943 |

この事前・基準・倍率は数値例で、実RNAから得た値でも推奨設定でもない。
局所事前はすでにPKを許す仮の分布であり、PKフリーBPPを忠実に再現するものではない。

次の精度比較では物理パラメータを固定し、調整は従来282配列のみ。
refinementなし・同一LPC BPP・DD改良beam100・最大50反復を維持し、
補正0、既存DP線形補正、局所確率変換、候補集合内の期待利得を比較する。
確率変換と長さ配分の変更を分け、少数のeta,tauで較正し、tau=1/eta=0も診断に残す。
全対F1、PK対F1、陰性RNAの偽PK、時間で判断し、較正loglossだけで採用しない。
既知900配列を新たな独立確認集合と呼ばず、新しい評価集合で固定設定を確認する必要がある。
