# DD beam 200：50反復と100反復の全件比較（2026-10-05）

2022年論文の[公開ZIP](https://zenodo.org/records/4923158)に含まれる単一配列全11,843本を、DD beam 200・反復上限50/100で比較した。全件23,686実行に欠測・失敗は0。別途36本×2条件×3回の216実行を、単一CPUで逐次測定した。

100反復の全体平均F1は50反復より+0.00005、長鎖816本では+0.00069。全体では改善309本、同点11283本、悪化251本だった。時間比とメモリは以下の測定値に基づいて判断する。

## 条件と精度指標

- `--decoder dd -e lpc -t auto,auto -r 1 --beam-size 100 --dd-beam 200 --dd-patience 0 --dd-max-iter 50`または`100`。孤立対は許容しない。PK追加スコア、追加上界、exchange、extra recoveryは無効。交差beam 100、witnesses 16。
- 反復上限はauto閾値/refinementの各DD solveに適用される。最適性の停止条件は残る。plateau停止は無効であり、既定patience=20の比較ではない。
- 12–4381 nt。short ≤150、medium 151–500、long ≥501。bpRNA-1m 3,437本、Rfam 14.5 8,406本。ZIPは前回確認済みの同一データで、配列を除外しない。論文Table 1より公開Rfamが945本少ない点は前回報告と同じ。アラインメントの共通構造予測は対象外。
- 主指標は完全一致する塩基対の配列ごとのF1平均（macro）。PPV/SEN、全塩基対を合算したmicro、交差塩基対の精度も保存する。空参照・空予測のF1は1、分母0のPPV/SENは0。PK分類は参照構造による。
- 前回と同じsolverなしReleaseバイナリ。C++ソース`1d88e79f88665d606ad84f6974959f9ced3c02f8`、GCC 13.3.0、`-O3 -DNDEBUG`、Cortex-X925/aarch64。今回C++・既定値の変更はない。

## 設定の判断

今回の条件では、通常の候補はbeam 200・50反復のままとする。100反復は全体F1の増加+0.00005に対して全件時間総和が1.773倍、逐次再測定でも1.761倍だった。長鎖のF1増加も+0.00069で、184本では悪化した。反復増加だけを一律の精度改善策として採用する根拠は弱い。

全塩基対を合算するmicro F1の改善はmacroより大きいので、長い配列の塩基対数を重く評価し、追加時間を許容する用途では100反復も比較候補になる。メモリ使用量の差は小さく、選択の主なトレードオフは時間と精度である。今回の評価に基づいてC++の既定値を変更してはいない。
